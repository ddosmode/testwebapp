# Документация TestWebApp

## Введение

Добро пожаловать в документацию TestWebApp. Основная идея приложения — создать платформу commerce для юридических товаров и услуг внутри Telegram,
обеспечивая простой способ просмотра товаров, управления корзиной и оформления заказов.

!!! warning
    TestWebApp является демонстрационным проектом и не предназначен для использования в продакшене без дополнительного аудита безопасности и hardening.

**Ключевые возможности:**

- Просмотр каталога юридических товаров и услуг с фильтрацией по категориям
- Добавление товаров в корзину с управлением количеством
- Оформление заказа с выбором города и несколькими способами оплаты
- Отслеживание заказов в реальном времени с обновлением статусов
- Юридическое согласие для товаров с ограничениями
- Управление документами для заказов
- Профиль пользователя и история заказов

## Системные требования и настройка

!!! note
    Это руководство ориентировано на Windows/MacOS/Linux.

### Требования:

- **Операционные системы**: 
    - Windows/MacOS/Linux: Проект можно запустить на любой из этих платформ, но рекомендуется деплоить на Linux сервер.

- **Необходимое ПО**: 
    - **Docker и Docker-Compose**: Требуются для контейнеризации и оркестрации сервисов приложения. Совместимы с Windows, MacOS и Linux.

!!! danger
    Некоторые этапы настройки могут потребовать финансовых затрат (например, сервер, домен). Убедитесь, что вы осведомлены о возможных расходах.

### Требования к деплою:

#### Продакшен (Production):

- **Сервер с доменом и SSL сертификатом**(1).
    { .annotate }

    1. Например, можно получить через Let's Encrypt Certbot.

- **Nginx:** веб-сервер, который можно использовать как обратный прокси. Он используется для маршрутизации запросов соответствующим сервисам (нашему фронтенду и бэкенду).

Подробные шаги по продакшен деплою описаны в [Руководстве по продакшен деплою](production-environment.md).

#### Локальный деплой (Development):

- Протестировать проект можно на **локальной машине**.
- Используйте **Ngrok** для доступа по домену и SSL сертификата во время локального тестирования.
- Это потребует создания аккаунта в Ngrok, настройки одного статического домена и сохранения домена для дальнейшего использования.
- Если у вас есть статический IP, вы можете его использовать, но тогда вы暴露自己的个人IP给WebApp用户。

Подробные шаги по локальному деплою описаны в [Руководстве по локальному деплою](development-environment.md).

### Состав проекта:

Проект состоит из следующих компонентов:

- **Frontend**: React + TypeScript приложение, собранное с помощью Vite.
- **Backend**: Состоит из нескольких компонентов:
    - **REST API**: Разработан на [FastAPI](https://fastapi.tiangolo.com/) с [SQLAlchemy](https://www.sqlalchemy.org/) в качестве ORM,
      и [Alembic](https://alembic.sqlalchemy.org/en/latest/) для миграций базы данных.
    - **Telegram Bot**: Построен на основе [aiogram](https://docs.aiogram.dev/en/latest/) (точка входа подготовлена).
- **База данных**: [PostgreSQL](https://www.postgresql.org/) для продакшена, [SQLite](https://www.sqlite.org/) для локальной разработки.
- **Redis**: [Redis](https://redis.io/) используется для кэширования и хранения сессий.
- **Nginx**: Используется как обратный прокси в продакшене для маршрутизации запросов.
- **Документация**: Собрана с помощью [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/).

## Краткий обзор

!!! question
    Интересно, какие возможности предлагает TestWebApp? Вот краткий обзор для начала.

TestWebApp предлагает ряд функций, направленных на улучшение опыта commerce юридическими товарами внутри Telegram. Вот краткий обзор:

- **Каталог товаров**: Просматривайте и ищите юридические товары и услуги, организованные по категориям.
- **Корзина**: Добавляйте товары, корректируйте количество и управляйте корзиной перед оформлением заказа.
- **Оформление заказа**: Завершайте покупки с выбором города и несколькими способами оплаты.
- **Отслеживание заказов**: Отслеживайте ваши заказы в реальном времени с обновлением статусов и историей.
- **Юридическое соответствие**: Принимайте юридические условия для товаров с ограничениями.
- **Управление документами**: Загружайте и управляйте документами, связанными с заказами.
- **Профиль пользователя**: Управляйте информацией профиля и просматривайте историю заказов.

!!! example
    Если вы установили темную тему в Telegram, интерфейс TestWebApp адаптируется для отображения темных элементов, согласуясь с вашими визуальными предпочтениями.
