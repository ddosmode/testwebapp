# Инициализация зависимостей

Этот раздел описывает, какой софт и библиотеки нужно установить перед запуском TestWebApp.

## 1. Системные требования

### Backend

- **Python 3.12+**: Backend написан на Python и требует версии 3.12 или выше.
- **Docker и Docker Compose**: Рекомендуемый способ запуска всех сервисов. В качестве альтернативы можно запускать сервисы локально, если все зависимости установлены.

### Frontend

- **Node.js 18+**: Требуется для установки зависимостей и сборки фронтенда.
- **npm**: Менеджер пакетов Node.js.

### База данных и кэш

- **PostgreSQL 16+**: Используется в продакшене как основная база данных.
- **Redis**: Используется для кэширования и хранения сессий.
- В режиме разработки можно использовать **SQLite** через `aiosqlite` — отдельная установка PostgreSQL не требуется.

## 2. Установка зависимостей бэкенда

### Вариант A: Запуск через Docker (рекомендуется)

Если вы используете Docker Compose, зависимости устанавливаются автоматически во время сборки образа бэкенда.

```bash
docker compose build backend
```

### Вариант B: Локальный запуск

```bash
cd backend
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -e ".[bot]"
```

## 3. Установка зависимостей фронтенда

```bash
cd frontend
npm install
```

## 4. Проверка установки

```bash
# Backend
cd backend
python -c "import app; print('Backend OK')"

# Frontend
cd frontend
npm run build
```

!!! tip
    Если вы используете Docker Compose, проверку можно пропустить — зависимости проверяются при сборке.

## 5. Дополнительные инструменты

- **Alembic**: Уже включен в зависимости бэкенда. Используется для управления миграциями базы данных.
- **pytest**: Включен в зависимости бэкенда для запуска тестов.
- **MkDocs**: Требуется для локальной сборки документации.

```bash
pip install mkdocs-material
mkdocs serve
```

После успешной установки переходите к [выбору режима деплоя](development-environment.md).
